<center><h1>📸 Snapchat Clone</h1></center>
<p>Snapchat Clone est un projet de démonstration qui réplique certaines fonctionnalités clés de l'application Snapchat. Ce projet utilise React Native pour le frontend, avec une API Node.js pour le backend, et inclut des fonctionnalités telles que l'authentification sécurisée, le stockage des utilisateurs, et des notifications interactives.</p>

<h2> 🚀 &nbsp;installation</h2>
<p align="left">
    git clone <br>
    <code>cd snapchat-clone</code> <br>
    <code>npm install</code> <br>
</p>

<h2> ▶️ &nbsp;exécution</h2>
<p><strong>Android</strong></p>
<p align="left">
    <code>npx react-native run-android</code> <br>
</p>
<p><strong>iOS</strong></p>
<p align="left">
    <code>npx pod-install</code> <br>
    <code>npx react-native run-ios</code> <br>
</p>
